# Formaty Launch Checklist

Marketing and distribution playbook for getting Formaty in front of developers.

## Before launch

- [ ] **Deploy** the latest build (static export) to the production domain and verify `SITE_URL` is set correctly in production env
- [ ] **Verify share cards**: post `https://formaty.dev` to a chat (Slack/Discord) and confirm the og:image renders (og.png is now generated by `bun scripts/gen-og.mjs`)
- [ ] **Set GA4** via `NEXT_PUBLIC_GA_MEASUREMENT_ID` in the API Keys UI, then confirm events fire with the consent banner accepted
- [ ] **Repo polish**: confirm topics on GitHub (json, formatter, developer-tools, json-tools, devtools), add the GitHub repo link from the app footer, and make the README screenshot/GIF
- [ ] **Demo GIF**: record a 20-30s screen capture of the playground (beautify → convert → diff → types) and add it to the README
- [ ] **Enable GitHub Sponsors** on the repo (Settings → Sponsors) if you want the support link
- [ ] **Set up Buy Me a Coffee** at buymeacoffee.com (footer link is already wired to kdkumawat)

## Launch day

- [ ] **Product Hunt** - create a listing: tagline "Free local-first toolkit to format, convert, compare and query JSON, XML, YAML, TOML & CSV", category Developer Tools, link to the playground
- [ ] **Show HN** (news.ycombinator.com) - title: "Show HN: Formaty - local-first JSON/XML/YAML/TOML/CSV toolkit in your browser", add a comment with the backstory + link
- [ ] **r/SideProject + r/webdev + r/selfhosted** - post with the demo GIF, honest framing, invite feedback
- [ ] **dev.to / Hashnode** - write "I built a local-first JSON toolkit" post with embedded demo
- [ ] **X/Twitter** - 3 posts across launch week with the GIF, the "works offline" angle, and a type-generation demo
- [ ] **LinkedIn** - one post aimed at dev/eng audiences

## After launch (ongoing)

- [ ] **Submit to directories** (free): BetaList, Uneed, Microlaunch, AlternativeTo, Toolify, SaaSHub, There's An App For That, GetApp, dev.to tags
- [ ] **Awesome lists** - PR to awesome-json, awesome-dev-tools, awesome-web-dev
- [ ] **Content SEO** - add 1-2 guides per month targeting long-tail queries: "JSON vs YAML", "how to diff JSON responses", "what is a UUID v7"
- [ ] **Collect feedback** - add a link in the app/docs to GitHub Issues
- [ ] **Iterate** - watch GA4 for drop-off on the landing page and playground first-run

## Key messages (repeat these everywhere)

1. 100% local - data never leaves your browser (the #1 differentiator vs competitors that upload)
2. Free forever, no sign-up
3. One workspace replaces 5+ separate tools
4. Works offline once loaded
5. Keyboard-first power-user experience
